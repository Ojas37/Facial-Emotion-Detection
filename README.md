# Facial Emotion Detection 🎭

A real-time facial emotion detection system built using **Python**, **OpenCV**, and **DeepFace**.  
The model detects faces in a video stream and classifies emotions such as **happy, sad, angry, surprised, neutral**, etc., displaying them with confidence scores.

---

## 🚀 Features

- Real-time face detection using **Haar Cascade Classifier**  
- Emotion classification with **DeepFace (CNN-based models)**  
- Displays **dominant emotion** with confidence percentage  
- Robust error handling for smooth real-time performance  

---

## 🛠️ Technologies Used

- **Python 3**  
- **OpenCV** – for image processing & face detection  
- **DeepFace** – for emotion recognition  
- **TensorFlow/Keras** – used internally by DeepFace
